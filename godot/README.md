# Godot workspace

Open `project.godot` with Godot 4.3 or newer.

The current foundation scene provides:

- responsive viewport sizing
- keyboard movement using WASD or arrow keys
- drag-based touch movement on the left side of the screen
- GL Compatibility rendering for broad browser/mobile support
- a dependency-free boot scene for reliable smoke testing

This is deliberately a small bootable baseline. Combat, enemies and progression are added only after this scene is verified in the editor and as a web export.
